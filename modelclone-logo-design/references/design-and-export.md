# Design And Export

Use the active user locale, owned brand facts and manual/autonomous gates in the main skill. Do not replace existing ad production quality rules.

## existing-brand-assets

For ads, use the owned genuine logo as supplied. Do not redraw, restyle, distort or hallucinate its lettering. Preserve aspect ratio and adequate clearance.

## new-logo-brief

Only create a new identity when requested. Establish name, audience, use cases, personality and constraints from available context. Distinguish logo work from a product-ad request.

## concept-exploration

Offer a small budget-appropriate set of meaningfully different concepts with clear rationale. Validate the basic silhouette in monochrome before adding finishes; no mandatory paid variant count.

## vector-construction

Prefer simple editable geometry and coherent spacing. Sanitize SVG before display: exclude executable code, foreign objects and external references. A raster image is not an editable vector deliverable.

## legibility-and-scale

Inspect small and large sizes, light/dark backgrounds, counters and clear space. Check wordmark spelling exactly; raster generation is not authoritative typography.

## refinement

Preserve the selected direction and change only the requested attributes. Reinspect balance and recognition after changes; do not regenerate approved alternatives unnecessarily.

## mockups-and-delivery

Use an approved flat logo as immutable source for optional presentation mockups. Generate paid imagery only through available ModelClone tools and budget gates. Deliver actual available file formats and distinguish concept previews from production assets.

## Independent design process

Define the mark's hardest use case first: small avatar, app icon, packaging, signage or printed label. Establish what must be recognizable at that size, whether the name needs to be read and which approved elements must remain. Use an existing logo for ordinary advertising; identity exploration is a separate explicit request.

For new concepts, connect each direction to a clear brand attribute and vary the underlying idea rather than only hue or rotation. Compare wordmark-led recognition against a standalone symbol when context warrants it. Start with simple monochrome forms to expose balance, silhouette and negative-space problems. Decorative texture or mockup lighting must not conceal a weak basic mark.

Create a concise comparison for each viable concept: intended meaning, distinguishing construction, strongest application and tradeoff. Select the number of concepts according to scope and budget, not a fixed minimum. Preserve the user's selected direction through revisions, with a clear statement of which property changed and what remained stable.

## Construction and export checks

For an editable vector, use actual clean SVG geometry with consistent viewBox, deliberate grouping and predictable fill/stroke behavior. Remove scripts, event handlers, external resource references and unsupported embedded content before display. Inspect path intersections, accidental gaps, alignment and clipping. Fonts in a wordmark require appropriate rights and a reproducible export; do not claim editable text where the delivered paths no longer contain it.

Test the chosen mark at the minimum intended size, in monochrome, on light and dark surfaces and beside real content. Check that counters remain open, thin strokes survive, spacing is balanced and the wordmark is spelled exactly. Define clear space and permitted color variants from the tested result rather than arbitrary universal dimensions.

Deliver only actual generated formats, with dimensions and transparent/opaque background state documented. Retain the editable master where available and derive raster exports from it. A generated photograph of a logo on a wall is a presentation mockup, not the master artwork or proof of trademark availability. Do not claim trademark clearance, uniqueness or production manufacturing suitability without the relevant independent checks.

## Advertising application

Apply a supplied genuine mark with preserved proportions, appropriate contrast and clearance. Product-ad end cards should prioritize product identification and the approved CTA over decorative brand effects. Inspect the exact final export for logo distortion, label legibility and cutoff text. Paid showcase images use ModelClone tools and the active review mode; no external provider keys or upstream generation scripts are needed.
